# Campus Events Website 🎓

A static web application built to display upcoming campus events, travel packages, and destinations. This project was developed collaboratively by a 5-person team using Git/GitHub for version control and is fully containerized for deployment using Docker.

## 🚀 Technologies Used
* **Frontend:** HTML5, CSS3
* **Bundler:** Parcel
* **Containerization:** Docker (Nginx Alpine)
* **Version Control:** Git & GitHub
